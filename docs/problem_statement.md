# BUG-ZERO: AI-Powered Code Bug Finder

Developers, especially students and beginners, lose hours finding bugs by hand. Existing tools are
language-specific, rule-based, give cryptic errors, keep no history and offer no personal accounts.

BUG-ZERO is a web app that uses an LLM API to find bugs in code written in any language, explain them
in plain language, suggest corrected code, rate severity, and save every analysis to the user's history.

See README.md for setup and architecture.
